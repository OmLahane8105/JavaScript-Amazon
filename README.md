# Amazon Frontend Clone

A frontend e-commerce shopping website inspired by Amazon, built using HTML, CSS, and JavaScript.

## Features

* Product listing and browsing
* Product search
* Shopping cart management
* Add and remove cart items
* Delivery option selection
* Checkout and order summary
* Order history
* Order tracking interface
* Persistent cart and order data using browser localStorage

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES Modules)
* DOM Manipulation
* LocalStorage API

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Run the project using a local development server, such as the **Live Server** extension.
4. Open `amazon.html` through the local server.

> Run the project through a local server rather than opening the HTML file directly, because the project uses JavaScript modules and local JSON data.

## Project Pages

* `amazon.html` — Product listing and shopping
* `checkout.html` — Cart and checkout
* `orders.html` — Order history
* `tracking.html` — Order tracking

## Data Storage

Cart and order information are stored in the browser using `localStorage`. Checkout, order placement, and tracking are frontend demonstrations and do not process real payments or connect to a production backend.

## Purpose

This project demonstrates frontend development skills, including DOM manipulation, JavaScript modules, event handling, browser storage, and interactive user interface development.
